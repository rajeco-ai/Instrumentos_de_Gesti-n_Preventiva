ANEXO 12 · PÁGINA WEB DE SEIS FORMATOS

1. Abra el archivo index.html con Chrome, Edge, Firefox o Safari.
   No necesita instalar software ni conexión a Internet.
2. Seleccione un formato en el menú lateral.
3. Diligencie los campos. La información se guarda en ESTE navegador y dispositivo.
4. Use «Exportar respaldo» para descargar un archivo JSON con todos sus registros.
5. Use «Importar» si desea restaurar ese respaldo en otro navegador o equipo.
6. Para un PDF, abra el formato deseado y pulse «Imprimir / PDF»;
   en el cuadro de impresión seleccione «Guardar como PDF».
7. Para incluir todos los formatos en un único PDF, seleccione «Imprimir todos».

IMPORTANTE: estos formatos son instrumentos académicos propuestos, no aprobados
ni validados institucionalmente. No cargue datos sensibles en equipos compartidos.
Para publicar el sitio en Internet, recuerde que el archivo funciona totalmente
en el navegador; no cuenta con una base de datos compartida ni autenticación.
